# De landingspagina staat op de branch gh-pages

De pagina voor box3balans.nl (`index.html`, `CNAME`, afbeeldingen) staat op een eigen branch `gh-pages` zonder gedeelde geschiedenis met `main`, en GitHub Pages publiceert die branch direct. Hij hoort niet in `main` en wordt niet samengevoegd. Verhuizen naar een map in `main` met een workflow om te publiceren is in oktober 2026 voorgesteld en door de eigenaar afgewezen; stel het niet opnieuw voor zonder nieuwe reden.

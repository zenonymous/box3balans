# Box3balans runs at the user's own place, never hosted for others

_Nederlands: [0001-zelf-hosten.md](../../adr/0001-zelf-hosten.md)_

An overview of everything a household owns and owes, plus keys for exchanges, doesn't belong with a third party. Box3balans is therefore software you run yourself, on a NAS, home server or laptop, and not a service we offer. That also rules out choices a hosted service would make, such as accounts for several households or data going to a server of ours; external services are only asked for public data (prices, blockchains) and, with your key, for your own accounts. The check for new versions only happens if you turn it on.
